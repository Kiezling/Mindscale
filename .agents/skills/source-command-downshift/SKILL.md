# source-command-downshift

Use this skill when the user asks to run the migrated source command `downshift`.

## Command Template

Review recent routing efficiency.

1. Read recent Git history and the compact logs in `.Codex/logs/`.
2. Sample up to five completed workhorse tasks with meaningful oracle coverage.
3. Identify categories now safe for Haiku/mechanical routing.
4. Measure whether repeated escalations point to weak specs/oracles rather than model limits.
5. Recommend precise provider-mapping changes without changing the shared capability tiers.
6. Append a memo of at most 12 lines to `.Codex/logs/routing-reviews.md`.

Do not run implementation or spend Fable credits for this review.
